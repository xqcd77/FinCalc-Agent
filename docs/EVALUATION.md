# 指标与对照说明

| 指标 | 定义与分母 |
|---|---|
| 答案准确率 | 当前官方答案匹配器通过题数／全部163题，拒答或错误保留在分母 |
| Numeric EM | 数值答案按评测器的数值规约匹配；不是所有文本答案EM |
| Valid Plan Rate | 最终计划fields非空且formula_id既非空也非unsupported／163；结构可用，不是完整金融公式正确率 |
| 数值需求Recall@10 | Top10至少有一块提供所需数值的需求数／350条冻结所需输入，micro平均 |
| 证据块MRR@10 | 160道需外部报告题，首个相关块排名的倒数平均；Top10外为0 |
| 固定需求绑定完整率 | 按完整流程冻结的模型需求检查全部绑定齐全的题数／163 |
| 重复工具调用率 | 参数可还原的同工具、同参数重复调用／可还原调用数；未知参数单列 |

检索qrels对所有163题进行了处理，160题需要报告数值、3题只用题目条件；350条所需输入中348条定位到来源，2条未定位仍在召回分母。
标注由AI辅助完成，没有独立人工仲裁，可能存在漏标。结果说明的是该冻结标签口径下的表现。

## 对照边界

58.86%／0.3645来自旧重排链路；纯BM25＋BGE-M3＋RRF结果是66.57%／0.4063。
当前R1为71.43%／0.6446，不能把旧重排数字改名为纯混合检索数字。
历史未微调RAG采用NF4，当前LoRA＋R1采用BF16，检索版本也不同；计划+8.59pp、准确率+12.27pp仅是整体系统差值。

14.72%→55.21%是关闭／开启完整工作流的绑定完整率，需求清单来自最终模型计划，不是独立gold充分性。
不能把它改称“答案正确且证据充分”或语义Faithfulness。
当前主报告答案正确且模型绑定完整为60/163（36.81%）；未独立测量语义Faithfulness。
