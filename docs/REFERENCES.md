# 参考与第三方资源

- [Fin-R1](https://github.com/SUFE-AIFLM-Lab/Fin-R1)：参考工作流、数据筛选、训练和评测的文档组织；未复制其RL实现。
- [FinQA](https://github.com/czyssrs/FinQA)：金融表格数值推理与可执行程序方向的研究参考。
- [FinanceComplexQA](https://huggingface.co/datasets/Multilingual-Multimodal-NLP/FinanceComplexQA)：第三方中文财报问题与文档来源。
- FinAR-Bench：本地训练数据改造来源，按原数据来源与许可使用；本发布不包含原始或改造后的完整样本。
- [BGE-M3](https://huggingface.co/BAAI/bge-m3)、[bge-reranker-large](https://huggingface.co/BAAI/bge-reranker-large)：检索与重排模型。
- [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B)：语言模型基座。
- [PEFT](https://github.com/huggingface/peft)、[Transformers](https://github.com/huggingface/transformers)：训练与模型加载。

模型与数据的版权及许可属于各上游。下载脚本不等于再分发许可。
当前源码没有新增开放许可，仓库所有者可以后续选择许可；不要推断第三方资产自动继承同一许可。
